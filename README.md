# SE_Master_Thesis
This repository compiles the scripts produced during my master thesis in the Technau Lab

Scripts used to produce results and figures mentionned in the thesis are placed in folders according to the Material and Methods parts : OMA, Clytia orthologs search, functional annotations, single cell analysis and visualization of synteny and reads. 

Scripts are not meant to be runnable as most of the data they rely on is not yet published. 

Quarto documents with the figures produced are available in the single_cell_analysis folder.
